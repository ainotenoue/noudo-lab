# 面積図メーカー v1.0
https://ainotenoue.github.io/noudo-lab/

## 目的
食塩水の面積図を「覚える図」ではなく、量を動かして理解するための道具として触れるプロトタイプ。

## v1.0 仕様
- A / B の2つの面積図を同じテーブル上に表示
- 初期値は A・B ともに「4%・100g」
- A は初期状態でロック（基準）
- B は「食塩水の重さ」「濃度」をスライダーで変更
- A のロック解除後は A も変更可能
- 重さ → 横幅
- 濃度 → 高さ
- 食塩量 → 面積（中央に g 表示）
- A / B は必ず同一スケール
- 底辺は同じテーブル面に接する
- 数値変更に合わせてリアルタイムに伸縮

## 起動
index.html をブラウザで開いてください。
GitHub Pages にそのまま配置しても動作します。
